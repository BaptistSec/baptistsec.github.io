File fingerprint checker

Compare a file with a reference fingerprint without uploading it.

A fingerprint is a short value calculated from the file's bytes. This tool uses a method called SHA-256 and shows 64 letters and digits. A match is not proof that a file is safe or who made it.

Choose your file

Up to 16 MiB (16,777,216 bytes). The tool reads the whole file into memory; this limit keeps the job small. It stops a calculation after 30 seconds. It does not open or run the file.

Paste exactly 64 hexadecimal characters: 0-9 and a-f. Uppercase is accepted. Spaces at the start or end are ignored, but spaces inside are not. Get the reference through a source you trust separately from the download.

What a comparison tells you

A matching value means this calculation matches your reference. It does not check the publisher's identity, detect malware or authorise opening the file. If someone can replace both the file and the reference, they can make them match. A fingerprint from the same untrusted download page adds no independent reason to trust it.

A different value means the calculation does not match that reference. Differences such as line endings also change the value. Check the file, reference and intended version before deciding what to do.

Your file stays here

The calculation runs on this device. File contents, names, references and results are not uploaded or saved by this tool. Clear removes them from the page. Closing or reloading also clears the page. The website still makes ordinary requests to load its own code; source links open only if you choose them.

Cancel stops this tool's background calculation and discards its result. Choose a saved file that will not change while it is read. This is not a locked or frozen copy.
