# Tidy Desk Digital

Plain-English workplace security tools and learning resources by William Baptist (BaptistSec).

[Open the tools and guides](https://baptistsec.github.io/)

## Start here

| Project | Purpose |
| --- | --- |
| [The Working Day](https://baptistsec.github.io/the-working-day/) | Practise responding to fictional workplace security requests. Free, browser-based learning for UK small-business staff. |
| [Payment Check Companion](https://baptistsec.github.io/payment-check-companion/) | A checklist for checking supplier payment and bank-detail change requests. It does not approve payments or verify bank accounts. |
| [Email Header Checker](https://baptistsec.github.io/email-header-checker/) | Inspect reported email checks locally. It does not identify phishing or prove a sender is genuine. |
| [AI Work Sharing Companion](https://baptistsec.github.io/ai-work-sharing-companion/) | A staff guide and blank workplace rule template for deciding what can be shared with AI tools. |

The site also links to Python guides, file-checking utilities, older learning projects and the work-in-progress CHAIN game. Each project has its own requirements and limits.

## About this repository

This repository contains the public site. Open `index.html` in a browser to view the home page locally, keeping the site files together. Some tools and the course live in separate repositories; their hosted links need an internet connection.

Security resources are general learning aids, not a security audit, recognised qualification or guarantee that a request is safe. Follow your workplace's policies and use its known reporting routes.
