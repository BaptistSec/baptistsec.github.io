CSV identifier import check

Spot leading zeros and long digit strings before importing a file into a spreadsheet.

Product codes and other identifiers name things; they are not amounts to calculate. Choose those columns yourself. A warning means review your import settings, not that the value is wrong.

1. Read a saved CSV

UTF-8 text, with an optional initial encoding marker (BOM). Up to 1 MiB (1,048,576 bytes), 1,000 data records and 65,536 UTF-16 text units per field. Some characters use two units. The first record must name the columns.

2. Choose identifier columns

Only choose columns whose values are identifiers. Names are matched exactly, not trimmed or changed. The file's header names appear here; keep them private.

What this checks

In your chosen columns, only non-empty strings made entirely of ASCII digits 0-9 are checked. More than one digit starting with 0 gets a leading-zero warning. More than 15 digits gets a potential precision-loss warning. A value may get both. Spaces, signs, decimals, exponent forms, other digit characters and empty cells are not checked. No warning does not mean these other formats will be preserved.

Use comma separators and double quotes around fields containing commas or line breaks. A quote inside a quoted field is written twice. This deliberately strict reader stops on quotes inside unquoted fields, text after a closing quote, unfinished quotes or inconsistent field counts. It accepts LF, CRLF and CR line endings and preserves spaces. It does not recognise every CSV dialect. A semicolon-separated file may appear as one column, so check the displayed header names before continuing.

Keep the original export

The file is read locally, not uploaded, repaired or saved. The whole file and its parsed values stay in this page's background worker until you clear, replace the file, reload or close the page. Clear terminates that worker. Cancel discards the current read or check; jobs stop after 30 seconds. This does not lock the file or create a frozen copy.

Choose identifier columns as text in your spreadsheet's import settings, inspect the preview and compare imported values against the original. Formatting a damaged number afterwards cannot recover lost zeros or digits. This tool does not open or configure your spreadsheet, validate account numbers or recover lost data.
