Checking IPv4 Subnet Membership in Python

Check whether saved IPv4 addresses fall inside a supplied network range. This is a local number check, not a network scan.

You need Python 3.10 or later, a plain-text editor and a command window. No extra packages. Examples are fictional. Sources checked 7 October 2026. Tested locally with Python 3.10.12.

Printed code may wrap long lines. Copy the program from the web page or its original .py file, not from this printout.

1. Create an address list

Internet Protocol version 4 (IPv4) addresses have four dot-separated numbers, such as 192.0.2.10. A subnet is an address range. The /24 in 192.0.2.0/24 says the first 24 address bits, the zero-or-one parts of its binary number, define the range, here 192.0.2.0 through 192.0.2.255. These example addresses are reserved for documentation, not actual systems to contact.

Save this plain-text file using UTF-8, a common way to store text, as Addresses.txt, one address per line:

192.0.2.0
192.0.2.10
192.0.2.255
198.51.100.4
not-an-address

2. Save the complete program

Save this as CheckSubnet.py in the same folder. It reads local text and compares numbers. It sends no network traffic and changes no settings or input files. Code panels scroll sideways on narrow screens so the original lines are preserved.

import ipaddress as IpAddress
import sys as Sys
from pathlib import Path


def CheckSubnet(FileName, NetworkText):
    Network = IpAddress.IPv4Network(NetworkText, strict=True)
    with Path(FileName).open("rb") as Input:
        Data = Input.read(1048577)
    if len(Data) > 1048576:
        raise ValueError("input exceeds 1 MiB")
    Lines = Data.decode("utf-8-sig").splitlines()
    if len(Lines) > 1000:
        raise ValueError("more than 1000 input lines")
    Inside = 0
    Outside = 0
    Invalid = 0
    for Number, Line in enumerate(Lines, start=1):
        Text = Line.strip()
        try:
            Address = IpAddress.IPv4Address(Text)
        except ValueError:
            Invalid += 1
            print(f"Line {Number}: invalid IPv4 address")
            continue
        if Address in Network:
            Inside += 1
            print(f"Line {Number}: {Address} inside")
        else:
            Outside += 1
            print(f"Line {Number}: {Address} outside")
    print(f"Network: {Network}; inside: {Inside}; outside: {Outside}; invalid: {Invalid}")
    return 1 if Invalid else 0


def Main():
    if len(Sys.argv) != 3:
        print("Usage: python3 CheckSubnet.py addresses.txt NETWORK", file=Sys.stderr)
        return 2
    try:
        return CheckSubnet(Sys.argv[1], Sys.argv[2])
    except (OSError, UnicodeError, ValueError) as Error:
        print(f"Check stopped: {Error}", file=Sys.stderr)
        return 2


if __name__ == "__main__":
    raise SystemExit(Main())

3. Run the range check

python3 CheckSubnet.py Addresses.txt 192.0.2.0/24

Use your installation's Python 3 command if it is not named python3. Quote paths containing spaces. Expected output:

Line 1: 192.0.2.0 inside
Line 2: 192.0.2.10 inside
Line 3: 192.0.2.255 inside
Line 4: 198.51.100.4 outside
Line 5: invalid IPv4 address
Network: 192.0.2.0/24; inside: 3; outside: 1; invalid: 1

The first and last addresses in this range count as inside it. That does not mean every address can be assigned to a device. Duplicate input addresses are separate lines and count again. Invalid address text is not echoed.

4. Test boundaries and stopped input

Save these three lines as Edges.txt:

192.0.2.0
192.0.2.1
192.0.2.2

python3 CheckSubnet.py Edges.txt 192.0.2.0/31
python3 CheckSubnet.py Edges.txt 192.0.2.1/32
python3 CheckSubnet.py Edges.txt 192.0.2.1/24

The /31 test includes the first two addresses, not the third. The /32 test includes only 192.0.2.1. The last command stops: 192.0.2.1 is not the starting network address for /24. Strict parsing does not silently change it to 192.0.2.0/24.

Also test a missing file, an Internet Protocol version 6 (IPv6) address such as ::1, an address with extra leading zeros such as 192.0.2.01, and a blank line between addresses. The missing file stops the run; the three invalid-address cases are reported by line. Spaces around a valid address are removed before parsing. A final line ending does not create an extra blank line.

5. Interpret the exit code and limits

The exit code, a small result number for another program or command window, is 0 for a completed run with no invalid lines, 1 for a completed run containing invalid lines, and 2 for a command, network definition or file-reading error. Outside addresses are normal results, not errors; a run with only outside addresses still returns 0. An empty file reports zero counts and returns 0, not proof that any address was checked.

IPv4 only. Supply a network such as 192.0.2.0/24; Python also accepts a mask written as four dot-separated numbers: 192.0.2.0/255.255.255.0 defines the same range as 192.0.2.0/24. An address without a mask is treated as /32, a range containing only that one address. The program accepts UTF-8 with or without an initial byte-order marker (BOM), reads at most 1 MiB (mebibyte), exactly 1,048,576 bytes, and permits at most 1,000 input lines. It checks each address directly instead of building a list of every address in the subnet, so a /0 range does not require such a list.

Membership does not prove reachability, ownership, permission, access allowed by a firewall (a traffic-filtering rule) or that an address is suitable for a device. It is not a network scanner. Use a saved copy that will not change while read. Review code before running it. If you save output, use a new filename, never the input filename. Reports show valid addresses and may reveal work-network details, so keep them private.
