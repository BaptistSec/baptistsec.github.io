Your first game

  1. Get ChainDemo.py from the main branch of the repository linked above.
  2. You need Python 3. Open an Ubuntu terminal in the file's folder, at least 104 columns by 48 rows, and run python3 ChainDemo.py. No extra Python packages are needed.
  3. Use left/right to aim, Space to fire and Q to quit. The title screen explains the other controls.

The Windows console is untested. This is a work-in-progress build, not a finished game release.
