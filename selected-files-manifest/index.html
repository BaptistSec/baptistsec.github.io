Selected-files fingerprint list

Save fingerprints for a small set of files. Choose files again later to see which selected bytes match.

A fingerprint is a SHA-256 code calculated from file contents. A saved list is called a manifest. This checks the files your browser supplies, not whether a whole folder or backup is complete.

1. Choose what to check

Use one picker. For a folder, paths start inside the selected folder, so its outer name can change. For individual files, names must be unique. Keep the saved list outside the folder you check.

Folder selection may not work in older browsers. Use individual files if your browser cannot supply folder paths.

2. Create or compare

Leave empty to create a new list. To compare, choose the original JSON file made by this tool and use the same picker type.

Up to 1,000 selected files, 16 MiB (16,777,216 bytes) per file, 256 MiB in total, and a 1 MiB saved manifest. A job stops after two minutes. Files over the per-file limit are marked skipped; an incomplete selection cannot create a manifest.

Download new manifest

The browser chooses where this download is saved and may ask about existing names. Check its prompt and keep your original manifest. This page does not write to your selected files or replace a baseline.

A match only means these selected bytes match this saved list. It does not show the original was correct, a file opens, a backup restores, or that a file is safe.

Read the states

Hashed means a fingerprint was calculated. Unchanged means the selected file matches the saved fingerprint and size. Changed means it does not. Added means its path was not in the saved list. Not selected means a saved path was absent from this selection, not proof that it was deleted. Unreadable means the browser could not read/hash the file. Skipped means it exceeds the per-file limit. Those last two states make the check incomplete.

What this cannot check

Every selected file within the limit is fully hashed, even if size or date looks unchanged. There are no date-based shortcuts.

Your browser may omit files it cannot expose. Empty folders are not recorded. This page cannot identify symbolic links (shortcuts to other filesystem locations), control whether the browser follows them, or prove that all files were selected. It cannot detect every change during a read or produce a frozen filesystem snapshot. There is no unstable-file verdict. Re-select files after a change, and avoid editing them while checking.

The entire file is read into memory, one at a time. Nothing is uploaded or kept in browser storage. Clear removes the selections and results. Cancel or changing a selection removes computed results; current picker selections remain until cleared, replaced, reloaded or closed. Downloaded manifests remain where you saved them. No permissions or file handles are retained.

Relative paths are matched exactly, with no renaming or content-based move detection. Ambiguous case/Unicode paths and malformed lists are rejected. Filenames with line breaks, control characters or backslashes are not supported.

Check one file's fingerprint or use the command-line Python fingerprint guide. Neither is a complete-folder verification claim.
